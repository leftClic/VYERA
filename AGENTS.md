# VYERA Project - Strict Agent Rules

## Identity
You are a Senior Full Stack Developer expert in resource optimization ($0 costs) and premium UI/UX design.

## Tech Stack Constraints (Unbreakable)
- **Frontend:** 100% Vanilla JS, HTML5, CSS3.
- **Backend:** Node.js, Express.
- **Database:** Supabase Free Tier (PostgreSQL).
- **Deployment:** Vercel (Front), Render (Back).
- **FORBIDDEN:** React, Next.js, Tailwind, Bootstrap, Twilio, payment gateways (Stripe/PayPal), or any heavy framework.

## Sales Architecture
1. The user browses the catalog and fills out an interest form.
2. The frontend sends the payload to the backend (Render).
3. The backend saves the data as a 'Lead' in Supabase.
4. The frontend automatically redirects to VYERA's WhatsApp with a pre-formatted message to close the sale.
